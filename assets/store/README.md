# App Store artwork

These images use the Crabigator pixel brand and the iOS sample-session screen. They were created with the built-in image generation tool on November 5, 2026, then exported to Apple's required sizes with macOS sips. Both PNG files are opaque.

- `app-store-header.png`: 3840 x 1646 pixels, product page header.
- `app-store-search.png`: 1920 x 1280 pixels, search results.

[Apple creative asset specifications](https://developer.apple.com/help/app-store-connect/reference/app-information/creative-assets-specifications)

## Header prompt

Use case: ads-marketing. Create a polished Apple App Store product-page header for Crabigator, a mobile remote control for coding agents. Recompose the supplied branding into a wide 21:9 banner, exactly 3840 by 1646 pixels if possible. Reference 1 is the existing brand composition; reference 2 is the exact pixel crab mascot. Preserve the mascot's silhouette, peach face #FFB98A, coral extrusion #E8775A, cream eyes, and sharp rectangular pixels. Dark ink #141A21 background. Center a confident horizontal brand lockup: pixel crab beside the exact word CRABIGATOR in the reference pixel lettering. Beneath it, one short legible cream line: "Your coding agents, on the go". Behind the lockup, very subtle abstract terminal-window outlines and sparse rectangular code-line marks in muted slate and coral, suggesting remote coding without pretending to be an app screenshot. Strong editorial composition, generous quiet space, all meaningful content inside the middle 70% width and middle 60% height for cropping. Restrained, sophisticated developer-tool brand, flat pixel art with clean edges, no blurry glow or excessive decoration. No other text, no platform logos, no badges, no prices, no URLs, no watermarks. Opaque background, no alpha. This is final production marketing artwork, not a mockup of an App Store page.

## Search results prompt

Use case: ads-marketing / compositing. Create a polished Apple App Store search-results creative for Crabigator, a mobile remote control for coding agents, in a landscape 3:2 composition, exactly 1920 by 1280 pixels if possible. Reference 1 is the existing peach-and-coral pixel crab brand and wordmark, preserve that identity. Reference 2 is a real iPhone screenshot of Crabigator's clearly labeled sample-session demo. Use that actual screenshot faithfully as the central screen of a clean front-facing phone silhouette on the right half, without inventing controls, rewriting the screenshot, adding fake UI, or hiding its demo label. Left half: the small pixel crab and the word "CRABIGATOR" above a large beautifully typeset cream headline with exact text "Your coding agents.\nOn the go." Use only those words outside the real screenshot. Deep ink #141A21 background with restrained dark slate terminal-window geometry and small coral pixel accents. Peach #FFB98A and coral #E8775A brand colors. Precise, calm, high-end visual hierarchy, generous safe margins, one clear phone, no hands, no extra devices. The phone and headline stay within the central 80% of the canvas. Preserve crisp pixel art in the mascot and accurate legible UI in the reference screenshot. No Apple logo, no platform or marketplace logos, no prices, URLs, awards, badges, or watermarks. Opaque RGB artwork. This is standalone marketing art, not a mockup of a store page.
