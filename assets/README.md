# Icon Assets

SVG icons used throughout the Crabigator project.

## Source

All icons are from [Phosphor Icons](https://phosphoricons.com/) using the **fill** weight variant.

- License: MIT
- ViewBox: `0 0 256 256`
- Default fill: `currentColor`

## Exception

The crab icon (`crab.svg`) is a custom icon for the Crabigator brand.

## Usage

In HTML/markdown:
```html
<img src="assets/icon-name.svg" width="16" height="16">
```

In the landing page (inline):
```html
<svg viewBox="0 0 256 256" fill="currentColor"><path d="..."/></svg>
```

## Available Icons

Run `ls *.svg` to see all available icons. Current count: 88 icons.
